## What it is

One unified API for more than 100 crypto exchanges and prediction markets, so the same code can fetch market data and place orders on different venues.

## Caution

Plumbing, not a strategy. Funding-rate gaps close fast and fees eat the thin ones, so do the maths after costs. Run both legs on testnet before real money.

## Status

Forked Oct 27, 2026. Nothing here has been run, configured, or connected to any account, API key, or real money. Paper / dry-run first, and only after a walk-forward backtest with fees, a look-ahead check, and 30 days on paper.
